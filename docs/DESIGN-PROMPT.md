> 用法：把下面 `===` 之间的全部内容复制，粘贴到网页版 Claude（claude.ai）。它包含了重设计所需的全部上下文，无需附加文件。
> 本次设计约束（你已选定）：**视觉方向完全开放**（要 2–3 个差异化方案）、**覆盖全部界面**（主窗口三页 + 三个辅助窗口 + 原生截图工具栏的视觉规格）、**移除 AI 功能**。

```
我在重新设计一款 Windows 桌面截图工具「NexSpot」的全部界面，请你做 UI/UX 设计。这是 Tauri v2 应用：Rust + Win32 做截图内核，前端是 React 18 + TypeScript + Tailwind CSS v4 + Zustand 的 Webview。我要的是高完成度的视觉设计 + 可落地的前端代码，不是泛泛的建议。

## 产品是什么
NexSpot 是"微信截图级"的即时截图 + 原生标注工具，卖点：
1. 零延迟原生覆盖层截图（按下热键瞬间进入框选）。
2. 双渲染引擎：GDI（极速、纯色）与 Vello/WGC（GPU 加速、支持 Neon/Glass 等风格化效果）。这两个引擎互相独立。
3. 工作流驱动：每个全局热键 = 一条可配置流水线（采集模式 + 引擎 + 输出格式 + 保存位置）。
4. 四种采集模式（均可在任一引擎下运行）：区域选取 / 全屏 / 窗口捕获 / 固定尺寸快照。
5. 扩展：PIN 贴图合集、滚动长截图、OCR、活动记录。
目标用户：重度截图用户、开发者、设计师、文档/客服人员。
注意：本次设计**不包含任何 AI 功能**，请勿在界面中出现 AI/对话/智能助手相关元素。

## 需要你设计的界面（全部）

### A. 主窗口（一个窗口内，左侧 40px 垂直活动栏切换三页）
活动栏（Navigator）：纯图标 + hover 提示，底部一个"窗口置顶"开关。三页：

1. **Dashboard / 工作流列表**（最核心页）
   - 展示所有工作流，每条信息：名称、规格（引擎+模式，如 GDI·区域选取）、输出格式（PNG/JPG）、状态（热键是否冲突 + 引擎是否就绪，两个独立指示）、目标文件夹快捷入口、绑定的热键、操作（立即触发 / 编辑 / 删除）。
   - 系统预设工作流不可删除只能编辑；用户工作流可删。
   - 顶部有"新建工作流"；空态要友好。
   - 需要"一眼扫描"：哪条热键冲突了、哪个引擎没就绪，要立刻看出来。

2. **Activity / 活动中心**
   - 左：实时活动流（每条：类型图标[截图/OCR/滚动] + 名称 + 时间戳 + 文件路径）。
   - 右：按工作流分组的"存储池"快捷入口（点进去打开对应文件夹）。
   - 顶部一个"LIVE"实时指示。

3. **Settings / 设置**（左侧子 Tab 导航 + 右侧内容）
   子 Tab：
   - 通用：保存路径、标注字体、界面语言。
   - 工作流：增删改工作流（弹出表单：名称、热键录制、采集模式、引擎、输出格式、保存位置、存文件/存剪贴板开关）。
   - 高级：JPG 质量滑块、默认导出格式(PNG/JPG)、并发度、默认快照尺寸；Vello 引擎开关 + 5 种风格选择(Default/Neon/PaperCut/Sketch/Glass) + 高级效果开关；日志维护(查看/清空)。
   - 外观：主题(亮/暗/跟随系统)、强调色。
   - 捐赠页。

### B. 三个独立辅助窗口（无边框/半透明，悬浮在桌面）
1. **PIN 合集窗**：截图被"钉"成卡片，多张卡片在一个合集窗内。每张卡片可独立 保存/复制/删除，可拖出粘贴到别处。卡片标题栏可拖动；窗口可缩放；有最小尺寸；卡片多时翻页；限制最大数量。整体像"可视化的临时剪贴板合集"。
2. **滚动长截图预览窗**：展示拼接出的长图，带保存/复制。
3. **OCR 结果窗**：展示识别出的文字，可复制。

### C. 原生截图工具栏（视觉规格，不需要 React 代码——这部分由 Rust 原生渲染）
框选完成后，选区下方浮出工具栏。工具：矩形、椭圆、直线、箭头、画笔、文字、序号、马赛克、撤销、PIN、保存、复制、关闭。
- 每个绘图工具点开有"二级属性条"：大小、颜色、(Vello 下还有)透明度、(矩形/椭圆)填充。
- 选中已画对象时显示方向手柄 + 连接线。
- 还有一个放大镜（取色/精确定位）。
请给出这个工具栏 + 属性条 + 选中手柄的视觉设计稿（配色、尺寸、图标布局、悬浮位置逻辑），我会让工程师在原生层还原。

## 现有技术约束（必须遵守）
- 暗色为主，但必须同时支持亮色主题（用 CSS 变量做主题切换）。
- 强调色用户可自定义（设计要用一个 --accent 变量统一驱动，不要硬编码强调色）。
- 文案要走国际化（中/英），所以别把布局做得依赖特定语言长度。
- Webview 不是浏览器标签，是无边框桌面窗口；主窗口尺寸偏紧凑（类似设置面板，不是全屏网页）。
- 图标可用 lucide-react。动效可用 framer-motion（克制）。
- 技术元数据（热键、格式、引擎名、路径）适合用等宽字体呈现。

## 现有设计令牌（当前是"工业暗色控制台"风，你可以推翻重来）
当前 CSS 变量（仅供参考，不要求沿用）：
  accent #3b82f6 / bg-main #09090b / bg-card #121214 / bg-subtle #18181b
  border #27272a~#3f3f46 / text-main #e2e2e7 / text-muted #a1a1aa
  圆角 2px(面板)/4px(按钮)，间距 4/8/12/16，正文 Inter，元数据等宽
当前风格偏"高密度、小字号、大量大写+字间距、细边框替代阴影、状态用色点色条"。
这一版偏冷硬工程感。我对方向**完全开放**——你可以保留这种工程克制感，也可以走更现代克制(Linear/Raycast 风)、更亲和、或任何你认为最适合"高频截图工具"的方向。

## 我要的产出
1. **2–3 个差异化的设计方向**，每个方向先用一段话说清楚：定位、情绪关键词、为什么适合这个产品、和其它方向的区别。
2. 每个方向给一套**设计系统**：配色（含亮/暗 + 强调色变量）、字体层级、间距/圆角、组件基调。
3. 选你最推荐的 1 个方向，给出**全部界面的高保真布局**：
   - 主窗口三页（Dashboard/Activity/Settings 各子 Tab）。
   - 三个辅助窗口（PIN 合集 / 滚动预览 / OCR）。
   - 原生工具栏 + 属性条 + 选中手柄 + 放大镜的视觉稿。
   - 优先用**单文件 HTML + Tailwind（CDN）的可交互原型**呈现，方便我直接预览；主窗口和每个辅助窗口可以是独立的 HTML 片段或同一页内分区。
4. 标出关键交互态：hover、选中、禁用、热键冲突(红)、引擎未就绪(黄)、空态。
5. 简要说明从当前实现迁移的注意点（哪些组件要重写、CSS 变量怎么映射）。

先给我 2–3 个方向的概览和设计系统让我选，我选定后你再展开全套高保真稿。
```

## 拿到网页版结果后怎么落地

1. 网页版会先给你 2–3 个方向 → 你选定。
2. 选定后它给单文件 HTML 原型 + 设计系统。
3. 把原型/设计系统贴回这个项目，让本地的 Claude Code：
   - 先按 [08-AUDIT](08-AUDIT.md) 的 B1/B2 修好前后端配置契约（重设计会直接用到这些字段）。
   - 把设计系统的 CSS 变量映射进 `src/index.css`（令牌已集中，换肤成本可控）。
   - 逐页改造 `src/components/` 下对应组件（页面清单见 [05-FRONTEND](05-FRONTEND.md)）。
   - 原生工具栏视觉稿交给后端 `render/toolbar/` 与 `render/vello_engine/renderer/ui/` 还原。
